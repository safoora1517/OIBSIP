# Twitter Sentiment Analysis NLP Pipeline

An end-to-end Natural Language Processing (NLP) pipeline classifying social media texts into positive, negative, or neutral sentiment using `scikit-learn` and `NLTK`.

---

## 📌 Project Overview
Public opinion and customer feedback on digital channels provide crucial commercial insights. This project builds a text preprocessing pipeline, extracts numerical features using TF-IDF, trains multiple classification algorithms, evaluates performance metrics, and conducts misclassification error analysis.

---
🛠️ Tech Stack
Language: Python 3.9+

NLP & Text Processing: NLTK, WordCloud, regex

Machine Learning: scikit-learn (TfidfVectorizer, MultinomialNB, LogisticRegression)

Visualization: matplotlib, seaborn
